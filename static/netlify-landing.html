⚠️ Important: Backend Required

AutoPointCloud requires a running Rust backend to function.
This Netlify deployment is serving static files only, which means the upload, processing, and visualization features cannot work without the backend API.

To use the full application, please deploy to a platform that supports Rust backends (see deployment options below).

info About AutoPointCloud

AutoPointCloud is a high-performance, web-based point cloud processing application built with Rust and Three.js. It features a clean Material Design UI and provides PCL-like functionality for processing millions of points directly through a web interface.

✨ Key Features

cloud_upload Multi-Format Support

Import PCD, PLY, LAS, LAZ, XYZ, and more formats with automatic detection

tune Advanced Processing

Voxel downsampling, outlier removal, filtering, and more with parallel processing

3d_rotation Interactive 3D Viewer

WebGL-powered visualization with orbit controls, coloring, and 60 FPS rendering

file_download Multiple Export Formats

Export to PCD, PLY, or XYZ formats with preserved attributes

🛠️ Technology Stack

Rust + Actix-web Three.js WebGL Material Design Rayon (Parallel Processing)

Quick Start

# Clone the repository
git clone https://github.com/sumeshthkr/autopointcloud.git
cd autopointcloud

# Build and run
cargo run --release

# Open browser to http://127.0.0.1:8080

The application will start on http://127.0.0.1:8080 with full functionality including upload, processing, and visualization.

help_outline

Why doesn't this work on Netlify?

Netlify is optimized for static websites and serverless functions (Node.js). AutoPointCloud requires a persistent Rust backend to handle file uploads, point cloud processing, and data management. These operations cannot be performed in a static-only environment.

For production deployment, use one of the recommended platforms above that support full-stack applications with Rust backends.
